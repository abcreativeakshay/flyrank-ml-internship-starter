# Decide Once: Identity Kit

One page. Every page, post and deck I make should be buildable from this sheet without new decisions.

## Fonts

- **Display / headings: Fraunces** (free, Google Fonts). A serif with character — it makes the page feel like a person's work, not a SaaS landing page, and it stays readable at big sizes.
- **Alt display / labels: Space Grotesk** (free, Google Fonts). For small caps-style labels, tags and the logo wordmark where Fraunces is too soft.
- **Body: Inter** (free, Google Fonts). Neutral, highly legible at small sizes, and it never fights the headings.

Rule: Fraunces for headlines, Inter for everything you actually read, Space Grotesk only for labels. No fourth font, ever.

## Palette

Built on my portfolio's warm charcoal and amber.

| Role | Hex | Use |
|---|---|---|
| Charcoal (base) | `#161210` | Page background — warm, not blue-black |
| Amber (accent) | `#f2a93b` | Headings highlights, links, the one number that matters per section |
| Panel | `#221b16` | Cards and case blocks, one step up from the background |
| Border | `#3a2f26` | Hairlines and dividers |
| Text | `#f3ead9` | Body text — warm off-white, never pure white |
| Muted text | `#b8a88f` | Captions, dates, secondary lines |
| Faint text | `#8a7a63` | Footers, fine print |

Rule: amber is a ration, not a paint. One or two amber elements per screen — the moment everything is amber, nothing is.

## Logo concept

A monogram: the letters **"AB"** set in Space Grotesk bold, amber (`#f2a93b`) on the warm charcoal (`#161210`), inside a simple square with slightly rounded corners. No icon, no gradient, no tagline in the mark itself — the letters have to work at 16 pixels and at 160.

**Favicon:** the same square, cropped tight — amber "AB" on charcoal, nothing else. If a tool needs a one-colour version, charcoal "AB" on amber is the approved inverse.

## Style note

Plain words, real numbers, dark warm page, one amber highlight at a time. If a page of mine looks like a template or sounds like a press release, it has failed this kit — rewrite it until it sounds like me.
